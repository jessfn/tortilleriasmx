# TortilleríasMX

PWA + API para captura de precios de la tortilla. Monorepo pnpm: `apps/web`, `apps/api`, `packages/shared`, `db`, `deploy`.

Credenciales solo en `.env` (ver `.env.example`), nunca en Git.

Avance: T-001 (estructura), validaciones compartidas, migración inicial (T-010) y script de despliegue (T-083).
